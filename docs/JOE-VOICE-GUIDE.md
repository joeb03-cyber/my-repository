# Joe voice guide

For AI-assisted interface copy and future drafting, conversational plausibility outranks polish.

- Use simple sentences, concrete language, direct opinions, and first person only where Joe has supplied the view.
- Preserve rough or informal wording when it communicates the idea clearly.
- Avoid poetic wellness language, therapeutic abstractions, motivational cadence, tidy rhetorical symmetry, and unnecessary metaphors.
- If a sentence sounds impressive but Joe would never naturally say it, it is wrong.
- Prefer “Naps are great. They’re underrated.” to an elegant explanation of intentional rest.
- Prefer “Do what you’ll consistently do.” to a polished maxim about optimal programs.

This is not authorization to rewrite Joe’s existing authored material automatically. Apply it to generated interface copy and drafts that Joe is reviewing.
